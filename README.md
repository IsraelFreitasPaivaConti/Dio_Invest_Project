# Dio_Invest_Project
O Projeto Dio Investe é uma pequena Planilha para ajudar você a se planejar financeiramente no longo prazo através de investimentos em FII's com sugestões de aportes% diversificação e sugestões de divisões baseado em perfis ( conservador, moderado e arrojado ).

O projeto utilizar fórmulas como 'VF' para o cálculo de juros compostos e 'PROCV' para chaveamento composto de distribuição do investimento baseado em se perfil.

Intervalos Nomeados:
- dividendos_final ( Rendimento final Baseado no Patrimônio total )
- patrimonio_acumulado ( Patrimônio total acumulado durante 2, 5, 10, 20 e 30 anos )
- rendimento carteira ( rendimento mensal%)
- salario ( Base para o aporte%)
- sugestão_investimento ( aporte% sugerido )
